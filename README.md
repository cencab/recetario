# RecipeFinder — Explorador de Recetas

Aplicación web interactiva desarrollada en React que permite buscar recetas de cocina internacionales consumiendo la API externa de TheMealDB. Este proyecto es la entrega final del bootcamp de desarrollo web.

## Funcionalidades

- Navegación SPA entre página de inicio y explorador con React Router.
- Búsqueda en tiempo real de platillos e ingredientes mediante la API pública de TheMealDB.
- Indicador de carga animado (Preloader) durante las consultas asíncronas.
- Renderizado paginado de resultados en bloques de 3 tarjetas con funcionalidad "Mostrar más".
- Ventana modal con detalle de ingredientes e instrucciones completas, con cierre mediante botón, overlay y tecla Escape.
- Diseño responsivo adaptado desde 320px sin desbordamiento horizontal.

## Tecnologías utilizadas

- React (Create React App)
- React Router DOM
- Fetch API nativo
- Metodología BEM y CSS Grid / Flexbox
- TheMealDB API
